## Transfer to Hannover–Lehrte

The SAE methodology derives comparable resident trip counts by main mode from
person-day data and uses those quantities to estimate the municipal mode split.
Multiplying the daily rate by the walking trip share gives expected walking
trips per resident per day. The transfer uses the 2020 GHSL residential count at
each origin. For a cell that straddles municipal limits, each share is based on
the intersected native GHSL pixels. The project reconciles the split to the
shared grid's resident total before applying the municipal rates.

The public state timing table describes walking trips with usable start times.
The duration table excludes regularly recurring work trips and includes imputed
durations. The two published bases are 19,774 and 20,080 weighted trips, or
18,339 and 18,591 unweighted, respectively. Their bases describe surveys. The
baseline transfers both state profiles to the entire municipal walking-trip
budget. The ratio 19,774 / 20,080 is used as one sensitivity case for the effect
of time-record coverage. The share excluded from the municipal walking budget by
all differences in eligibility remains unverified. The tables pool survey days.

Durations and departure times are modelled as independent. Start times are
uniform within each source window. The duration groups use midpoints and a
90-minute representative value for the open 60+ group, with 60 and 120 minute
sensitivity cases. These are modelling choices and scenarios. See the
[iteration plan](../plan/iteration-016.md) for the research references and
the planned route objective.
